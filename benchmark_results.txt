libgsml3parser benchmark results
================================

Hardware (dynamically detected at runtime; unified across all benchmark tests
and examples via gsml3parser/benchmark_hw.h):
  Intel(R) Core(TM) i9-9900K CPU @ 3.60GHz | base 3600 MHz | 1 socket, 8 cores,
  16 logical | L1 n/a | L2 n/a | L3 n/a | 64 GB RAM, 4 slots @ 3000 MHz |
  Windows 10.0 (build 19044)
  Note: cache sizes (L1/L2/L3) are reported as "n/a" on this VM because CPUID
  leaf 0x04 is emulated/masked; they are reported correctly on physical
  hardware (CPUID 0x04) and on Linux (/sys/devices/system/cpu/cache).

Struct sizes (all static_assert invariants pass):
  FlatHandler: 16 bytes (== 2 * sizeof(void*))
  ProtocolDispatcher: 35216 bytes (~35 KB compact table [16][136])
  ChannelPool: 2816 bytes (fixed arrays, no unordered_map)
  ShardedChannelPool<16>: 45192 bytes
  ParsedMessage: 416 bytes (variant of 12 PD domains, stack-resident)
  MSContext: 92 bytes
  SubscriberSession: 2056 bytes (context + 3 FSMs + timers + transactions + procedure runner + response)
  ProcedureStepResult: 32 bytes (<= 32)
  SMResult: 12 bytes (<= 16)
  Transaction: 24 bytes
  TimerManager: 1080 bytes
  TransactionManager: 536 bytes
  ProcedureRunner: 152 bytes
  TimerExpiry: 16 bytes (== pointer + enum; session-bound timer event)
  AuthChallenge: 20 bytes (<= 32)
  CipheringParameters: 2 bytes (<= 16)
  ResponseContext: 128 bytes (<= 160)
